# Reference

This section summarizes command syntax, built-in actions, errors,
configuration, and the schemas an action may declare. Use it to check an option or a return value while working;
links lead back to the chapters that explain the associated tasks. Making
the same requests from a program is covered in
[Using Juice from a program](../programs.html).
